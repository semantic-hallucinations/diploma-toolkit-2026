# Economic Justification Workspace

Эта директория предназначена для работы с экономическим обоснованием дипломного проекта.

## Структура

- `common.md` - общие вводные и требования руководителя по экономическому обоснованию.
- `methodical-guidance-2021.md` - извлеченный в Markdown текст методического пособия БГУИР 2021 года.
- `latex-template/` - пустой LaTeX-проект для сборки только раздела экономического обоснования и списка источников.
- `result/` - локальные результаты и промежуточные материалы по конкретной задаче диплома; директория игнорируется Git, кроме `.gitkeep`.
- `private/` - локальные исходные документы, шаблоны с личным содержимым и рабочие заметки; директория игнорируется Git.

Файлы в корне этой директории должны оставаться общей методической базой и справочными материалами, которые можно переносить между работами.

## Откуда Взяты Данные Репозитория

Основные данные по требованиям БГУИР и оформлению диплома взяты из официальных материалов БГУИР, сохраненных в `standards/official/bsuir/`.

Ключевые файлы:

- `standards/official/bsuir/bsuir-stp-01-2024-diploma-projects-general-requirements.pdf` - СТП 01-2024, основной стандарт БГУИР по дипломным проектам и работам.
- `standards/official/bsuir/bsuir-economic-justification-diploma-projects-2021.pdf` - методические указания БГУИР по экономическому обоснованию дипломных проектов.
- `standards/official/bsuir/bsuir-calendar-prediploma-practice-diploma-2025-2026.pdf` - календарный план БГУИР на 2025-2026 учебный год.
- `standards/official/bsuir/bsuir-methodical-recommendations-references.docx` - рекомендации БГУИР по оформлению списка источников.
- `standards/official/bsuir/bsuir-piks-diploma-2025-2026.html` - сохраненная страница БГУИР, с которой были взяты ссылки на материалы.

Список исходных URL и примечания о скачивании лежат в `standards/notes/sources.md`.

Также в репозитории есть:

- `standards/official/catalog/` - сохраненные страницы каталогов/статусов ГОСТ и СТБ, не полные тексты платных стандартов.
- `standards/unofficial/` - неофициальный чеклист, который можно использовать только как вспомогательный материал после сверки с СТП и нормоконтролем.
- `examples/diploma_template/` - пример LaTeX-шаблона диплома, включая пример экономического раздела в `examples/diploma_template/sections/sec_economics.tex`.

## Роль Экономического Обоснования В Дипломе БГУИР

По СТП 01-2024 пояснительная записка дипломного проекта обычно занимает 60-80 страниц без справочных/информационных приложений. Раздел технико-экономического обоснования должен занимать не более 18 процентов от общего объема записки.

В рекомендуемой структуре пояснительной записки экономический раздел идет после основного технического текста и до раздела охраны труда / экологической безопасности / энерго- и ресурсосбережения, заключения, списка источников и приложений.

Экономический раздел должен раскрывать технико-экономическое обоснование принятых решений и определение экономической эффективности внедрения полученных результатов. Конкретные вопросы раздела задаются заданием по дипломному проектированию и согласуются с консультантом по экономической части.

Методические указания БГУИР 2021 задают общую схему:

1. Характеристика проектного решения.
2. Стоимостная оценка затрат / инвестиций.
3. Стоимостная оценка результата / экономического эффекта.
4. Оценка экономической эффективности инвестиций.
5. Вывод об экономической целесообразности реализации проектного решения.

Конкретная методика выбирается по типу проекта: ПО для собственных нужд, ПО по индивидуальному заказу, ПО для массового рынка, новое изделие, усовершенствованное изделие, внедрение новой продукции, программно-аппаратный комплекс, система безопасности или НИР.

Для расчетов нужны актуальные исходные данные: цены и тарифы на ресурсы, зарплаты или рыночные ставки специалистов, актуальные налоги и отчисления, ставки рефинансирования и долгосрочных депозитов. В первую очередь данные рекомендуется собирать на предприятии преддипломной практики; если это невозможно, допускаются актуальные интернет-источники и экспертные оценки, но точность снижается.
