# Empty Economic Justification LaTeX Template

Минимальный LaTeX-проект для подготовки только раздела экономического обоснования и списка использованных источников в формате дипломной записки.

Сборка из корня репозитория:

```sh
python3 compiler/diploma_compile.py economic-justification/latex-template
```

Основные файлы:

- `sections/sec_economics.tex` - текст раздела экономического обоснования.
- `biblio/othercites.bib` - база источников для списка литературы.
- `references.tex` - подключение списка источников.
