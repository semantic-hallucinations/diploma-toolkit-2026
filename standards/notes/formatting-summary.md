# Formatting Summary

Research date: 2026-04-26.

Primary document: `СТП 01-2024. Дипломные проекты (работы). Общие требования`.

## Explanatory Note

Core formatting from `СТП 01-2024`:

- Paper: A4.
- Margins: left 30 mm, right 15 mm, top 20 mm, bottom 20 mm.
- Font: Times New Roman, 14 pt.
- Line spacing: 1.0, with 18 pt line height.
- Paragraph indent: 1.25 cm.
- Text alignment: justified.
- Section and subsection headings: left aligned and bold.
- Unnumbered major sections such as contents, abstract, introduction,
  conclusion, references, and appendices: centered and without paragraph indent.
- Page numbers: Arabic numerals in the lower right corner.
- Title page, abstract page, and assignment sheet are counted but not numbered.
- Each section is recommended to start on a new page.

Typical note structure:

1. Title page.
2. Abstract.
3. Assignment.
4. Contents.
5. Introduction.
6. Main sections.
7. Economic justification, if required by the assignment.
8. Labor protection, environmental safety, or energy/resource saving section, if
   required by the department.
9. Conclusion.
10. List of used sources.
11. Appendices.
12. Element list, if there are electrical schematic elements.
13. Project document statement.

The title page code format changed for students admitted from 2023: `СТП
01-2024` mentions the newer `6-XX-XXXX-0X` specialty-code format alongside the
older `1-XX XX XX` format.

## Figures

- Every illustration is treated as a figure.
- A figure should be near the first reference to it.
- The caption goes below the figure.
- The caption format is `Рисунок N – Title` or `Рисунок section.number – Title`.
- Figures in appendices use appendix-based numbering, for example
  `Рисунок А.1`.
- Every figure must be referenced in the text.
- Figures should be clear, meaningful, and not overloaded.
- If a full ESKD/ESPD scheme is reused as an explanatory illustration inside
  the note, remove frame, stamp, specification, excessive technical data, and
  irrelevant details.

## Tables

- The table title goes above the table.
- The format is `Таблица N – Title`.
- Tables should be placed after the first reference or on the next page.
- Repeated/continued tables should use continuation labels and repeat the header
  or column numbering.
- Do not leave empty cells when data is absent; use a dash.

## Formulas

- Formula numbers are written at the right edge in round brackets.
- Numbering by section is recommended, for example `(2.7)`.
- Appendix formulas use appendix-based numbering, for example `(Б.2)`.
- Explain symbols after the formula if they were not explained earlier.
- Refer to borrowed formulas with a source reference.

## References

`СТП 01-2024` still refers to `ГОСТ 7.1-2003` for the list of used sources.
However, status/catalog sources show that `СТБ 7.1-2024` is now active in
Belarus for bibliographic description. This is a likely normal-control question:
use the BSUIR methodical recommendations and ask the supervisor/normal
controller whether the list must already follow `СТБ 7.1-2024`.

Practical safe rule: keep source references in the text as square-bracket
numbers in the order of first mention, because this is directly described by
`СТП 01-2024`.
