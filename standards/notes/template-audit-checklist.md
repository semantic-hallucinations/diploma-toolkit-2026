# Template Audit Checklist

Research date: 2026-04-26.

Use this checklist when checking the LaTeX diploma template against the current
BSUIR requirements.

## Page Layout

- A4 page size.
- Left margin: 30 mm.
- Right margin: 15 mm.
- Top margin: 20 mm.
- Bottom margin: 20 mm.
- Main text: Times New Roman or metrically acceptable equivalent, 14 pt.
- Line height equivalent to 18 pt.
- Paragraph indent: 1.25 cm.
- Text justified.
- Page number in lower right corner.
- Title page, abstract, and assignment counted but not visibly numbered.

## Structure

- Title page matches the current BSUIR title-page sample and uses the correct
  specialty-code format.
- Abstract is present and fits the expected size.
- Assignment pages are included and counted.
- Contents follows the assignment.
- Introduction starts on a separate page and is no longer than two pages.
- Conclusion starts on a separate page and is no longer than about two pages.
- References appear before appendices.
- Appendices are referenced in text and ordered by first reference.
- Project document statement is present when required.
- Element list is present when electrical schematic elements are included.

## Numbering

- Sections use Arabic numbers without a trailing dot.
- Subsections are numbered within sections.
- Figures, tables, and formulas use either consistent section-based numbering
  or another allowed consistent numbering style.
- Appendix figures/tables/formulas use appendix-based numbering.

## Figures And Diagrams

- Every figure has a text reference before or near the figure.
- Captions use `Рисунок N – Title`.
- Captions are below figures.
- Large diagrams are readable after PDF generation.
- Formal algorithm/program/data/system schemes follow `ГОСТ 19.701-90`.
- Formal structural/functional schemes follow the ESKD scheme rules referenced
  by `СТП 01-2024`.
- Explanatory diagrams do not include unnecessary frames, stamps, or excessive
  technical data.

## Tables

- Every table has a text reference.
- Title format is `Таблица N – Title`.
- Table title is above the table.
- Continued tables are marked as continuations.
- Empty data cells are not left blank.

## References

- Text references use square brackets.
- Sources are numbered in first-reference order.
- Wikipedia-like open wiki resources are not used as sources.
- Bibliographic formatting is checked against the current department or normal
  control rule, especially because `СТБ 7.1-2024` is active in Belarus while
  `СТП 01-2024` still mentions `ГОСТ 7.1-2003`.
