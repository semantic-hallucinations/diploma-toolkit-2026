# Standards

Дата исследования: 2026-04-26.

Здесь лежат материалы по актуальному оформлению пояснительной записки
дипломного проекта БГУИР и графических материалов.

Главный найденный документ для 2025-2026 учебного года: `СТП 01-2024.
Дипломные проекты (работы). Общие требования`.

Приоритет для реальной дипломной записки:

1. Указания руководителя, кафедры и нормоконтроля.
2. `СТП 01-2024`.
3. Стандарты, на которые ссылается `СТП 01-2024`.
4. LaTeX-шаблон только как техническая реализация этих правил.

Отдельной актуальной публичной страницы именно кафедры ИИТ / специальности ИИ
по дипломному проектированию я не нашел. Сохраненная страница БГУИР относится к
кафедре ПИКС, но на ней опубликованы общеуниверситетские материалы БГУИР,
включая `СТП 01-2024`, и она относится к дипломному проектированию 2025-2026.

## Что Читать Сначала

- `notes/formatting-summary.md` - короткая выжимка по оформлению пояснительной
  записки: поля, шрифт, структура, рисунки, таблицы, формулы, источники.
- `notes/diagrams-and-flowcharts.md` - правила по блок-схемам, схемам
  алгоритмов, программ, данных, систем и другим графическим материалам.
- `notes/template-audit-checklist.md` - чеклист для проверки LaTeX-шаблона и
  собранного PDF.
- `notes/standards-status.md` - какие ГОСТ/СТБ актуальны и где есть спорный
  момент по библиографии.
- `notes/sources.md` - ссылки на источники и заметки о скачивании.

## Официальные Файлы БГУИР

Все файлы в `official/bsuir/` скачаны с сайта БГУИР.

- `official/bsuir/bsuir-stp-01-2024-diploma-projects-general-requirements.pdf`
  - основной стандарт БГУИР по дипломным проектам и работам. В нем структура
  диплома, требования к пояснительной записке, графической части, титульным
  листам, рисункам, таблицам, формулам, приложениям, ведомостям и защите.

- `official/bsuir/minedu-attestation-rules-2023-319.pdf`
  - постановление Министерства образования Республики Беларусь от 13.10.2023
  N 319 о правилах аттестации студентов при освоении программ высшего
  образования.

- `official/bsuir/bsuir-calendar-prediploma-practice-diploma-2025-2026.pdf`
  - календарный план мероприятий по преддипломной практике и дипломному
  проектированию в БГУИР на 2025-2026 учебный год.

- `official/bsuir/bsuir-economic-justification-diploma-projects-2021.pdf`
  - методические указания БГУИР по экономическому обоснованию дипломных
  проектов. Нужны, если в задании есть экономический раздел.

- `official/bsuir/bsuir-methodical-recommendations-references.docx`
  - методические рекомендации БГУИР по оформлению списка использованных
  источников.

- `official/bsuir/bsuir-example-abstract.docx`
  - пример оформления реферата дипломного проекта.

- `official/bsuir/bsuir-example-supervisor-review.docx`
  - пример оформления отзыва руководителя дипломного проекта.

- `official/bsuir/bsuir-example-review.docx`
  - пример рецензии на дипломный проект.

- `official/bsuir/bsuir-patent-literature-research-certificate-form.docx`
  - форма справки об исследовании патентной и научно-технической литературы по
  теме дипломного проекта.

- `official/bsuir/bsuir-element-list-template.xlsx`
  - шаблон перечня элементов. Полезен, если в проекте есть электрическая
  принципиальная схема и нужен перечень элементов.

- `official/bsuir/bsuir-specification-template.xlsx`
  - шаблон спецификации.

- `official/bsuir/bsuir-piks-diploma-2025-2026.html`
  - сохраненная HTML-страница БГУИР "Дипломное проектирование в 2025-2026
  учебном году", откуда взяты ссылки на документы.

## Статусы ГОСТ И СТБ

Файлы в `official/catalog/` - это не полные тексты платных стандартов, а
сохраненные страницы каталогов/статусов. Они нужны, чтобы понимать, какие
стандарты действуют в Беларуси.

- `official/catalog/gost-2-105-95-rb-status.html`
  - статус `ГОСТ 2.105-95` в Республике Беларусь. Это базовый стандарт ЕСКД по
  общим требованиям к текстовым документам.

- `official/catalog/gost-2-106-96-rb-list.html`
  - каталоговая страница, где виден `ГОСТ 2.106-96`. Он относится к текстовым
  документам ЕСКД и упоминается в `СТП 01-2024`.

- `official/catalog/gost-2-701-2008-rb-status.html`
  - статус `ГОСТ 2.701-2008` в Республике Беларусь. Это стандарт по схемам:
  виды, типы и общие требования к выполнению.

- `official/catalog/gost-2-701-2008-rb-list.html`
  - каталоговая страница, где `ГОСТ 2.701-2008` показан среди действующих
  стандартов Республики Беларусь.

- `official/catalog/gost-19-701-90-rb-status.html`
  - статус `ГОСТ 19.701-90` в Республике Беларусь. Это главный стандарт для
  схем алгоритмов, программ, данных и систем.

- `official/catalog/stb-7-1-2024-rb-status.html`
  - статус `СТБ 7.1-2024` в Республике Беларусь. Это новый стандарт по
  библиографическому описанию.

- `official/catalog/stb-7-1-2024-rb-list.html`
  - каталоговая страница, где `СТБ 7.1-2024` показан среди действующих
  стандартов.

## Заметки

- `notes/formatting-summary.md`
  - практическая выжимка из `СТП 01-2024`: A4, поля, Times New Roman 14,
  интервал, абзац, нумерация страниц, структура записки, правила рисунков,
  таблиц, формул и списка источников.

- `notes/diagrams-and-flowcharts.md`
  - что использовать для блок-схем и графических материалов: `ГОСТ 19.701-90`
  для алгоритмов/программ/данных/систем, `ГОСТ 2.701-2008` для видов и типов
  схем, и как это применять к AI/software дипломам.

- `notes/template-audit-checklist.md`
  - чеклист для будущей проверки шаблона: страница, поля, шрифт, структура,
  нумерация, рисунки, таблицы, формулы, источники.

- `notes/standards-status.md`
  - сводка по актуальности стандартов. Там отдельно отмечен конфликт:
  `СТП 01-2024` ссылается на `ГОСТ 7.1-2003`, но в Беларуси уже действует
  `СТБ 7.1-2024`. Это нужно уточнять у нормоконтроля.

- `notes/sources.md`
  - исходные URL, список успешно скачанных файлов и ссылки, которые на момент
  исследования отдавали `404`.
