# Unofficial Materials

Дата добавления: 2026-04-26.

Здесь лежат неофициальные вспомогательные материалы. Они полезны как чеклисты
и практические подсказки, но не являются нормативными источниками.

Приоритет всегда такой:

1. Указания руководителя, кафедры и нормоконтроля.
2. `СТП 01-2024`.
3. Стандарты, на которые ссылается `СТП 01-2024`.
4. Неофициальные чеклисты из этой директории.

## Файлы

- `unofficial-dp-materials-checklist.docx` - экспорт Google Docs документа
  `Чек-лист оформления материалов ДП`.

  Документ содержит практические напоминания по оформлению материалов дипломного
  проекта: текст пояснительной записки, перечисления, числительные, формулы,
  иллюстрации, таблицы, состав дипломного проекта, титульные и сопроводительные
  материалы.

  Источник:
  `https://docs.google.com/document/d/1buauo5WyjLUBJfx29Wskj8kRExgwJseLUz8SEQR8Ew0/edit?tab=t.0`

  Использовать только как вспомогательный чеклист. Любой спорный пункт нужно
  сверять с `СТП 01-2024` и актуальными указаниями нормоконтроля.
