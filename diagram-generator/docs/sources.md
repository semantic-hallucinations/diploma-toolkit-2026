# Diagram Sources

Дата исследования: 2026-04-26.

Основные источники для выбора и генерации software/AI диаграмм:

- OMG UML 2.5.1:
  `https://www.omg.org/spec/UML`
- ISO/IEC 19505-1:2012 status page:
  `https://www.iso.org/standard/32624.html`
- OMG BPMN 2.0.2:
  `https://www.omg.org/spec/BPMN/2.0.2/`
- OMG DMN:
  `https://www.omg.org/spec/DMN`
- ISO/IEC/IEEE 42010:2022:
  `https://standards.ieee.org/ieee/42010/6846/`
- OMG SysML 2.0:
  `https://www.omg.org/spec/SysML`
- The Open Group ArchiMate standards catalog:
  `https://publications.opengroup.org/standards/archimate`
- C4 model:
  `https://c4model.com/`
- Structurizr DSL:
  `https://docs.structurizr.com/dsl`
- Mermaid documentation:
  `https://mermaid.js.org/intro/`
- PlantUML:
  `https://plantuml.com/`
- draw.io documentation:
  `https://www.drawio.com/doc/`

Локальные материалы по оформлению диплома остаются в `standards/`.
Для диаграмм важны:

- `standards/official/bsuir/bsuir-stp-01-2024-diploma-projects-general-requirements.pdf`;
- `standards/notes/diagrams-and-flowcharts.md`;
- `standards/official/catalog/gost-19-701-90-rb-status.html`.
