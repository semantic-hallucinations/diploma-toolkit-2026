# Draw.io GOST Skill Option

Это внешний вариант для оценки, не часть текущего инструментария.

Источник: `https://github.com/ast-ashulga/as.drawio-gost.skill`

Что заявлено в репозитории:

- генерация `.drawio` файлов для алгоритмических блок-схем;
- ориентация на `ГОСТ 19.701-90 / ISO 5807:1985`;
- использование нативного draw.io XML;
- экспорт в PNG/SVG/PDF через draw.io desktop;
- mapping конструкций кода на ГОСТ-символы.

Почему исходники не скопированы сюда:

- в репозитории не указана лицензия;
- без лицензии нельзя безопасно включать чужой код в наш репозиторий;
- сейчас это только референс идеи, а не зависимость проекта.

Как можно использовать идею:

- посмотреть mapping кода на ГОСТ-символы;
- сравнить размеры, стили и маршрутизацию стрелок с нашими требованиями;
- взять подход `model -> draw.io XML -> PNG export`, но реализовать свои
  пресеты и проверки.

Для диаграмм, вставляемых в пояснительную записку как рисунки, рамки и
основные надписи не нужны. Рамки нужны только для официальной графической
части, если диаграмма оформляется как отдельный графический лист.
