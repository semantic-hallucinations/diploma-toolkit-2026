# BSUIR Draw.io Libraries Option

Это внешний референс, не зависимость текущего инструментария.

Источник: `https://github.com/C010UR/draw-io-bsuir-drawing-libraries`

Что есть в репозитории:

- библиотека `GOST 19.701-90.xml` с фигурами для схем по `ГОСТ 19.701-90`;
- библиотека `Drawing borders and headings.xml` с форматами листов, рамками и
  основными надписями.

Что полезно для нас:

- набор ГОСТ-фигур для сверки shapes;
- пример draw.io `<mxlibrary>`;
- пример размеров и названий элементов;
- подтверждение, что draw.io подходит для хранения таких preset-ов.

Что не нужно для рисунков в записке:

- рамки;
- основные надписи;
- листы A1/A3/A4 как графические документы.

Почему не копируем XML:

- в репозитории не указана лицензия;
- нам нужна проверяемая собственная библиотека preset-ов;
- чужой набор можно использовать как референс, но финальные параметры нужно
  сверять с локальными требованиями диплома.
